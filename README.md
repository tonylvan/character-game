# 🎮 汉字闯关游戏

一个寓教于乐的汉字学习闯关游戏，帮助孩子学习汉字、拼音和成语。

## ✨ 功能特色

- 🏠 **首页** - 国潮朱砂红风格设计
- ⚔️ **闯关模式** - 三种题型随机出题
  - 选字填空（成语、古诗、常见错别字）
  - 拼音写汉字
  - 汉字写拼音
- 📖 **汉字故事** - 字源、甲骨文、词组、例句
- 📝 **错题本** - 自动记录错题，支持专项练习
- 📊 **排行榜** - 前10名成绩展示
- 📚 **汉字学习** - 汉字浏览与详情
- 🗂️ **题库管理** - 自定义题库导入/导出
- 🔐 **家长管控** - 时间管理、难度设置

## 🛠️ 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 6
- **路由**: React Router DOM
- **样式**: CSS-in-JS (内联样式)
- **PWA**: 支持离线使用

## 📦 安装

```bash
# 克隆项目
git clone https://github.com/你的用户名/character-game.git

# 进入目录
cd character-game

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🎯 使用说明

1. 打开游戏首页
2. 选择闯关类型（混合闯关、成语填空、拼音写汉字等）
3. 选择年级和单元（可选）
4. 开始闯关！

## 📖 题型说明

| 题型 | 说明 |
|------|------|
| 选字填空 | 根据上下文选择正确的字或词 |
| 拼音写汉字 | 看拼音写出对应的汉字 |
| 汉字写拼音 | 给汉字标注正确的拼音 |

## 🔧 配置说明

### 家长管控

- 每日游戏时长限制
- 单次游戏时间限制
- 错字出现频率设置
- 拼音写汉字难度（简单/中等/困难）
- 闯关倒计时

### 自定义题库

支持添加自定义题目，格式如下：

```json
{
  "id": "custom-001",
  "type": "pinyin-to-char",
  "content": "míng tiān",
  "answer": "明天",
  "char": "明",
  "level": 1,
  "grade": "1-上册",
  "unit": 1
}
```
